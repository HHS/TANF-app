# Release 4.25.1

Patch release based on `release/v4.25.0`.

## Fixed

- Remove the parser-error count/link column from the Django admin Data Files list and its database aggregation to address the release 4.25 slowdown and timeouts (#6116, #6118).
- Preserve eager loading for STT, user, and summary data. Add regression coverage for latest/all-version selection and pagination without parser-error queries.

## Validation

- 18 focused admin/filter tests and changed-file lint passed on an identical backend source tree.
- The original hotfix was browser-tested locally with 100,000 synthetic data files and 100,000 parser errors.
- Staging verification is required before promotion. Latest-version selection remains a separate scaling limitation at very large data-file volumes.

No database migrations or new dependencies are required.
